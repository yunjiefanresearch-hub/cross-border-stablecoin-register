# External security review attestation template

This file is intentionally uncompleted. It must be filled and signed by an identified reviewer who is
independent of the implementation before a production-ready or independently reviewed claim is made.

- Revision SHA or ZIP SHA-256:

- Methods and tools:
- Threat-model findings:
- Dependency / SBOM / licence findings:
- Secret-scanning findings:
- Receipt and mandate findings:
- Severity-rated open findings:
- Remediation verified at revision:
- Final disposition: `pass` / `conditional` / `fail`
- Signature or verifiable attestation:

Do not commit credentials, private exploit details or sensitive evidence. Use private vulnerability
reporting for exploitable findings.
